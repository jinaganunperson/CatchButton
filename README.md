# 버튼잡기게임(C# 코딩)
## 개요
-C# 프로그래밍학습

-핵심 기능
1. 마우스 회피 (Mouse Evasion)
버튼 컨트롤 영역 내로 마우스 커서가 위치 할 경우, 버튼은 즉시 창 내부의 임의의 좌표로 이동합니다.
2. 클릭 및 난이도 조절 
버튼 클릭에 성공하면 '딩동댕' 효과음과 함께 축하 메시지 박스가 출력됩니다.
클릭 성공 시마다 버튼의 크기가 현재 대비 10%씩 축소되어 게임의 난이도가 점진적으로 상승합니다.
3. 게임 종료 (Game Over)
버튼을 클릭하지 못하고 20번 놓칠 경우 "게임 오버" 메시지가 출력됩니다.
종료 후에는 게임 내 모든 버튼이 비활성화(Disabled) 처리되어 추가 조작이 제한됩니다.
4. 초기화 및 재시작 (Reset)
우측 상단의 '다시 시작' 버튼을 클릭하면 점수, 놓친 횟수, 버튼 크기 등 모든 게임 데이터가 초기값으로 복구되며 게임이 재시작됩니다.

-화면구성
메인 버튼 ("나를 잡아봐"): 마우스 진입 시 도망가는 핵심 타겟 버튼입니다. 클릭 시 크기가 줄어들며 난이도를 조절합니다.

시스템 버튼 ("다시 시작"): 우측 상단에 고정되어 있으며, 클릭 시 모든 게임 데이터(점수, 횟수, 크기 등)를 초기화합니다.

## 구현시어려웠던점
- 버튼 이탈 방지 : 초기 구현 시 버튼이 폼 경계 밖으로 이동하여 일부가 가려지는 현상이 발생함. 버튼의 좌표 최댓값을 폼 너비 - 버튼 크기로 제한하는 수식을 적용하여, 버튼 전체가 항상 홤녀 내에 위치하도록 보정함.
- 사운드 리소스 적용 : 사운드 재생 시 파일 형식 불일치 및 경로 인식 불가로 인한 오류가 발생함. 파일의 형식을 변환시키고 적절한 디렉터리에 리소스를 배치하여 경로 탐색 오류를 해결함.
- 잠조 오류 해결 : 다시 시작 버튼의 객체명(Name)과 코드 내 이벤트 핸들러 명칭이 일치하지 않아 빌드 에러 발생.코드 전체의 참조 관계를 검토하고, Visual Studio 속성 창에서 컨트롤의 명칭을 코드에 맞게 통일하여 이벤트 연결 문제 해결.
- 특정 상황(포획 성공 및 게임 오버)에서 적절한 알림을 띄우기 위한 MessageBox 로직 구성에 어려움이 있었음.MessageBox.Show 메서드를 활용하여 성공 시와 종료 시의 출력 메시지를 구분하고, 게임 상태에 따른 조건부 출력 로직을 완성함.

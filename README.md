# 버튼잡기게임(C# 코딩)
## 개요
-C# 프로그래밍학습
-핵심기능: 버튼 컨트롤 영역 안으로 마우스가 들어가면 벼튼을 랜덤 위치로 이동시킨다. 버튼을 잡은 경우 딩동댕 소리가 나며 "축하합니다"라고 메시지 박스를 띄웁니다. 그리고 버튼의 크기가 10%감소하며 다음 단계가 시작됩니다. 버튼을 20번 놓치면 "게임 오버" 메시지를 출력하고 모든 버튼은 비활성화 처리됩니다. 게임을 더 하고싶은 경우 오른쪽 위에 있는 다시 시작 버튼을 누름녀 게임 정보가 초기화되며 게임이 다시 시작됩니다. 
-화면구성: "나를 잡아봐" 버튼, "다시 시작" 버튼, 폼 박스 상단 제목 표시줄의 점수와 버튼의 좌표.

## 구현시어려웠던점
- 초기에는 버튼이 화면 가장자리로 이동하여 버튼의 전체 모습이 보이지 않는 문제가 있었지만 버튼 위치의 최대값과 최소값을 수정하여 해결하였습니다.
- 효과음을 내기 위해 파일을 추가해야했는데 사운드 파일의 위치와 파일의 형식이 잘못되어 오류가 났었습니다. 자료를 찾아보니 .wav자료만 가능하고 bin/debug파일 내에 사운드 파일이 위치해야 한다는 사실을 알게되어 수정하였습니다. 
- 다시 시작 버튼의 이름을 코드상의 이름과 다르게 적어 실행 오류가 났었습니다. 하지만 코드를 찬찬히 읽어보고 버튼을 클릭하여 속성을 살펴보며 버튼의 이름을 바꾸어 해결하였습니다.
- 버튼을 클릭했을 때의 "축하합니다"와 20번 놓쳤을 때 "Game Over" 메시지를 띄우기 위해 메시지 박스를 만드는게 힘들었습니다.
- 폼 박스 상단의 제목 표시줄에 점수와 위치를 한꺼번에 띄울 수 있도록 하는 게 힘들었습니다.
